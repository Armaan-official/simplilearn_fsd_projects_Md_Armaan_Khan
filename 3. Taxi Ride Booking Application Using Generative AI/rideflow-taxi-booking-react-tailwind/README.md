# RideFlow — Taxi Booking React + Tailwind Starter

A responsive, modern taxi/ride booking front-end starter built with React, React Router and Tailwind CSS.

## Included

- Home / landing page
- About Us
- Services
- Contact
- Book a Ride
- Responsive navigation
- Light / dark theme with localStorage persistence
- Basic booking form validation
- Service selection
- Passenger selector
- Example fare estimation
- Consistent reusable UI components

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Production build

```bash
npm run build
npm run preview
```
